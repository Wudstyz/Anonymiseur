# Exemples / Examples

Fichiers d'essai **entièrement fictifs** (personne imaginaire « Jean Martin », coordonnées inventées) pour essayer
l'application sans risque. Glissez-les dans Anonymiseur. / **Entirely fictitious** sample files (an imaginary
"Jean Martin", made-up contact details) to try the app safely.

| Fichier | Ce qu'il contient |
|---|---|
| `photo-exemple.jpg` | Marque et modèle d'appareil, auteur, date et position GPS fictifs |
| `lettre-exemple.txt` | E-mail, téléphones, IBAN, carte bancaire, chemin et adresse IP fictifs : à tester avec « Masquer les informations personnelles » |
| `schema-exemple.drawio` | Schéma draw.io (page compressée) avec identité de l'éditeur, texte à masquer et photo embarquée |

Ces fichiers sont produits par `tests/make_fixtures.py`.
